# 動物界 分類 クイズ（門・綱・目・科）

動物名と説明から「門」→「綱」を当てる2段階4択クイズです（30問）。

## 機能

- 30問ランダム出題（シャッフル）
- Step 1: 門を選択（脊索動物門/節足動物門/軟体動物門/環形動物門/棘皮動物門/刺胞動物門）
- Step 2: 綱を選択（哺乳綱/鳥綱/爬虫綱/両生綱/条鰭綱/頭足綱/昆虫綱/クモ綱 ほか）
- 正解後に特徴カード表示（生態・特徴の解説）
- スコア・正答率リアルタイム表示

## 収録動物数

30種（ライオン・タコ・ミミズ・カブトムシ・ウニ・カエル・ワシ・クラゲなど）

## 技術仕様

- 静的SPA（単一 index.html）
- Tailwind CSS CDN
- XSS対策: textContent で表示（innerHTML への入力直接挿入なし）
- localStorage 不使用
